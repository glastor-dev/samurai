# 📖 Cómo Citar este Proyecto (Citation Guide)

Si utilizas **SAMURAI** en publicaciones académicas, especificaciones técnicas,
benchmarks o proyectos de software corporativo, por favor cita este repositorio
utilizando el estándar **CFF (Citation File Format)** nativo de GitHub o los
siguientes formatos.

GitHub renderiza automáticamente el botón **"Cite this repository"** en la barra
lateral derecha a partir del archivo [CITATION.cff](CITATION.cff).

---

## Formato BibTeX

```bibtex
@software{samurai_2026,
  author = {Glastor},
  title = {SAMURAI: Enterprise-grade software repository adhering to GitHub 2026 standards and DevSecOps architecture.},
  year = {2026},
  url = {https://github.com/glastor-dev/samurai},
  license = {Apache-2.0}
}
```

## Formato APA (7ª edición)

> Glastor. (2026). _SAMURAI_ (Versión 1.0.0) [Software de computación].
> https://github.com/glastor-dev/samurai

## Formato IEEE

> Glastor, "SAMURAI," 2026. [En línea]. Disponible en:
> https://github.com/glastor-dev/samurai.
